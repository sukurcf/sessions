A strong prompt is a small spec.

Start with the outcome. Add the context and rules that affect the answer. State how to prove it works.

Goal

What should change? Name the user or system outcome.

Context

Point to the files, patterns, examples, and relevant tests.

Constraints

State what must stay the same and what is out of scope.

Proof

Ask for a test, check, or observable result.

Vague
“Fix the tests.”
→
Useful
“Fix this test without changing the public API; run the focused test.”

A custom agent is a reusable role and tool set.

Use it when a recurring job needs a clear point of view, tool access, or safety boundary.

Create in VS Code
1Open Chat: Open Customizations.
2Choose Agents → New Agent (Workspace).
3Save a role such as pr-reviewer.agent.md in .github/agents/.
4Select it and test it on your small lab change.
→Review its instructions and tools before you use it.
Starter role 
Act as a read-only pull request reviewer.
Check correctness, test gaps, security, and scope.
For each finding, cite the file and line.
Ask a question when evidence is missing.
Do not edit, commit, or merge files.
RoleWhat the agent is responsible for.
ToolsOnly the tools the job needs.
BoundaryWhat it must not do.
TestCheck its output on a real, small diff.

01:25–01:40 · 15 min

A workflow is an agent that runs on a repository event.

Unlike an in-editor agent, a GitHub Agentic Workflow runs in GitHub Actions. Markdown describes the task. Frontmatter defines triggers and guardrails.

Two places for agent work

Developer→VS Code agent→Reviewed diff
GitHub event→Actions + agent→Safe output
Public preview · check current rules
Try it · design first

Draft a weekly repository status report.

1Use a Markdown source in .github/workflows/.
2Ask for a report from issues and pull requests; start read-only.
3Define a narrow safe output, such as creating a report issue.
4Review the trigger, permissions, safe output, and Markdown source.
Optional compile (only in an approved repo):
gh extension install github/gh-aw
gh aw compile

Do not trigger or merge a workflow until authentication, billing, permissions, and policy are reviewed.
