Customization in VS Code

What it is

Files and settings that teach Copilot your project rules, tasks and tools.

How it is useful
  • Same rules for every developer
  • Repeat a task with one command
  • Connect Copilot to outside tools and data

What it is

A saved AI role with its own instructions, tools and model.

How it is useful

Same expert behavior each time: planner, reviewer, tester.

  • Fields: name description tools model skills
  • Local harness only: agents handoffs

What it is

Many agent sessions run at the same time. Each session has its own task.

How it is useful

Do many tasks at once. A worktree keeps the files of each task apart.

Configure with

  • Isolation: New Worktree or Branch
  • Harness: Copilot, Claude or Codex — or run in Cloud

Subagents
What it is

A helper agent. It works in its own context and returns a short result.

How it is useful

Keeps the main chat small. Good for research, comparison and review. Not for small edits.

Configure with
  • Ask for a subagent in the prompt, or let the main agent choose
  • Agent file: user-invocable
    disable-model-invocation
  • Local harness: tools: ['agent'] and agents: [...]

Copilot Code Review

What it is

Copilot reviews a pull request and writes comments. Each comment has a severity: High, Medium or Low.

How it is useful
  • Fast first review before a human
  • Finds bugs, security issues and style errors
  • Apply a suggested fix in a few clicks
Effort levels
Lite
Fast, targeted
~$0.25
Balanced
Default.
~$1.50
Max
Many models. Preview.
~$10

Adaptive (preview) selects Lite, Balanced or Max within your configured limit.

Configure with
Request
Reviewers → Copilot → Request
gh pr create --reviewer @copilot gh pr edit N --add-reviewer @copilot
Effort level
Choose Lite, Balanced, Max or Adaptive under Reviewers. Admins set the default and maximum.
Automatic review
Settings → Rules → Rulesets → Automatically request Copilot code review — options Review new pushes and Review draft pull requests
Instructions
.github/copilot-instructions.md AGENTS.md REVIEW.md CLAUDE.md GEMINI.md .github/instructions/**/*.instructions.md
YAML: applyTo, excludeAgent: "code-review" skips the file in review
YAML setup file
.github/workflows/copilot-code-review.yml — runs-on and setup steps. Fallback: copilot-setup-steps.yml
Firewall
Settings → Copilot → Internet access (Code review section): Enable firewall, Recommended allowlist, Custom allowlist

Configure with
Code scanning

Finds code flaws. Results show as alerts and PR comments.

Fix security bugs before merge. Copilot Autofix suggests the fix. It is on by default with CodeQL.

Settings → Advanced Security: Default setup or Advanced setup (.github/workflows/codeql.yml)

CodeQL

GitHub's code analysis engine. It runs queries on your code.

Finds injection and unsafe data flow. Custom queries and CLI.

.github/codeql/codeql-config.yml (queries, paths, paths-ignore) — set with config-file in codeql-action/init

Secret scanning

Finds supported secret patterns in repository content and history.

Shows leaked secrets so you can revoke them.

.github/secret_scanning.yml (paths-ignore) — custom patterns in settings

Push protection

Blocks supported secrets when push protection detects them.

Helps stop leaks before the push. Detection has limits.

Settings → Advanced Security → Push protection — delegated bypass

Dependabot

Alerts on unsafe dependencies. Opens PRs to update them.

Keeps libraries secure and current.

Dependabot alerts and security updates in settings — .github/dependabot.yml (updates, schedule)

Source: docs.github.com/code-security. Code scanning and secret scanning are free on public repositories.

GitHub Copilot App

What it is

A desktop app to direct AI coding agents. Built on Copilot CLI. Runs on macOS, Linux and Windows.

Why use it
  • Use worktrees to keep parallel changes separate
  • Many repositories in one window
  • Issue, code, PR and merge in one place
  • Browser, terminal and diff next to the chat

Projects

Issues and PRs

Agent Merge
Handles checks and feedback. Merges only when enabled and permitted.
Panels
Diff, terminal and browser.
Canvases
A shared surface for you and the agent.
Customize
Plugins, skills, MCP servers. Connectors (preview).

GitHub Copilot CLI

What it is

An AI agent in your terminal. It reads files, runs commands and edits code.

How it is useful
  • Work without leaving the terminal
  • One-shot mode for scripts and CI
  • Plan, autopilot and fleet modes
  • Extend with skills, MCP servers and plugins

Use in GitHub Actions

What it is and why
  • Spec Kit: an open-source toolkit from GitHub
  • The spec records the agreed requirements.
  • Resolve known gaps before coding
  • Plan and tasks stay in line with the spec
Install
uv tool install specify-cli specify init my-project --integration copilot cd my-project

Needs Python 3.11+ and uv. Copilot syntax: /speckit-*

Commands and when to use them
/speckit-constitution
Once, at project start. Set the project principles.
/speckit-specify
Describe what and why. No tech stack. Creates the spec.
/speckit-clarify
The spec has gaps. Up to 5 questions. Run before plan.
/speckit-plan
Choose the tech stack and architecture.
/speckit-checklist
Check the quality of the requirements.
/speckit-tasks
Make an ordered task list: tasks.md
/speckit-analyze
Read-only check of spec, plan and tasks. Before implement.
/speckit-implement
Run the tasks and build the feature.
/speckit-converge
After implement. Adds missing tasks. Repeat until Converged.
Source: Spec Kit · Core flow: Specify → Plan → Tasks → Implement → Converge. Command syntax depends on the integration.

Saved agent tasks. They run on a schedule, on a GitHub event or on demand.

How it is useful

  • Local: runs on your computer
  • Cloud: runs even when your computer is off

  • Do not put secrets in prompts or logs

Stacked PRs

What it is

A chain of small PRs. Each PR targets the branch below it.

How it is useful
  • Each PR shows only its own diff
  • Merge from the bottom up
  • The next PR retargets after a merge
Configure with

  • gh stack init add push submit sync
  • Rebase stack in the PR UI
