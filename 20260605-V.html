IV. Overview 05

What is Copilot CLI.

A standalone agentic coding assistant in your terminal. Not just command suggestions — a full AI agent that reads files, edits code, runs commands, creates PRs, and self-corrects on errors.

Interactive mode

Run copilot to start a conversational session. Prompt, iterate, steer — just like chat, but in your terminal.

Programmatic mode

Use copilot -p "prompt" for one-shot tasks. Exits after completion — perfect for CI/CD and scripts.

Plan mode

Press Shift+Tab to cycle into plan mode. Copilot analyzes, asks questions, builds structured plans before writing code.

Autopilot mode

Full autonomous execution. --autopilot lets Copilot plan, code, test, and iterate without manual approval at each step.

All Copilot plans · macOS, Linux, Windows (WSL/PowerShell) · Install: npm install -g @githubnext/copilot-cli

V. Getting started 06

Get started.

Three commands to go from zero to productive.

# 1. Authenticate with GitHub
copilot login

# 2. Initialize project instructions
copilot init

# 3. Start an interactive session
copilot

copilot init

Analyzes your codebase and generates .github/copilot-instructions.md with build commands, architecture, and conventions. Run once per repo.

copilot login --host

Supports GitHub.com and GitHub Enterprise Cloud with data residency. Auth tokens stored securely in system credential store.

VI. Agentic workflows 07

Agentic workflows.

Copilot CLI doesn't just suggest — it acts. It reads your codebase, plans changes, edits files, runs tests, self-corrects, and opens PRs. All from slash commands.

/plan

Create a structured implementation plan before writing any code

/diff

Review all changes made in the current directory — with syntax highlighting

/review

Run the code review agent to analyze changes for bugs and security issues

/pr

Create, view, or fix pull requests for the current branch — right from the CLI

/delegate

Hand off changes to Copilot cloud agent — it creates a PR on a remote branch

/fleet

Run tasks in parallel with subagents — up to 32 concurrent agents

/research

Deep investigation using GitHub search, code search, and web sources

/undo

Rewind the last turn and revert file changes — safe experimentation

/compact

Compress context manually to keep long sessions fast and focused

VIII. Built-in agents 09

Built-in agents.

Copilot CLI auto-delegates common tasks to specialized sub-agents, each optimized for speed, cost, or depth.

code-review

High signal-to-noise code review. Analyzes diffs for bugs, security issues, logic errors.

explore

Fast codebase exploration. Searches files, reads code, answers questions. Safe to run in parallel.

research

Deep research agent. Generates reports from your codebase, repos, and the web.

rubber-duck

Constructive critique using a complementary model. Identifies weak points, suggests improvements.

task

Command execution (tests, builds, lints). Brief summary on success, full output on failure.

general-purpose

Full-capability agent for complex multi-step tasks. Runs in a separate context window.

Select agents via /agent · Auto-delegation: agents infer when to hand off tasks

IX. Rubber Duck 10

Rubber Duck.

A built-in second opinion. The rubber duck agent uses a complementary model to critique your proposals, designs, implementations, and tests — identifying weak points before they become bugs.

# Starts automatically on non-trivial plans
copilot> Implement exponential backoff retry
# (Timeline output shows automated critique)

# Manually trigger critique in active session
copilot> Rubber duck your plan.

# Or stress-test implementation changes
copilot> Get a critique of the changes so far.

Complementary models

Deliberately uses a different model family to avoid shared blind spots (e.g., Claude sessions use a GPT critic, or vice-versa).

Concrete, graded reviews

Automated at high-leverage steps. Evaluates logic, security, and design-flaws, categorizing reviews as Blocking, Non-blocking, or Suggestions.

X. Sessions & chronicle 11

Infinite sessions & chronicle.

Sessions persist, auto-compact, and can be resumed across time. Chronicle gives you insights into your development history.

/resume · Session persistence

Sessions auto-save. Resume any previous session by name, ID, or pick from a list. Sort by relevance, recency, or name.

/compact · Auto-compaction

At 95% token usage, Copilot automatically compresses history in the background — enabling virtually infinite sessions.

/context · Token visualization

See exactly how your context window is being used — detailed token usage breakdown across tools, code, and conversation.

/chronicle · Session history

Generate standups, get usage tips, improve workflows, and reindex session data. Your development journal, built-in.

/remote · Cross-device

Control CLI sessions from GitHub Mobile, Web, or VS Code — now GA (May 2026). Start locally, steer remotely.

/share · Export sessions

Export sessions to Markdown, interactive HTML, or GitHub Gists. Share context, decisions, and code reviews with your team.

XII. MCP & extensibility 13

MCP & extensibility.

Model Context Protocol lets you connect Copilot CLI to databases, APIs, internal services, and any external tool through a standard interface.

// ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "my-db": {
      "command": "npx",
      "args": ["@mcp/sqlite", "./db.sqlite"],
      "tools": ["*"]
    }
  }
}

Built-in MCP servers

github-mcp-server — issues, PRs, commits, code search, Actions
playwright — browser automation
fetch — HTTP requests
time — time utilities

Custom MCP servers

Add via ~/.copilot/mcp-config.json, .mcp.json in project root, or /mcp add. Local (stdio) and remote (HTTP/SSE) transports.

Enterprise MCP allowlist · OIDC token injection · OAuth re-auth · Headless client_credentials grant

XV. Security & permissions 16

Security & permissions.

Fine-grained control over what the agent can do. Trusted directories, tool approval patterns, and enterprise MCP allowlists.

Tool permissions

--allow-tool, --deny-tool with pattern matching: shell(git:*), write(src/*.ts), MCP(tool)

Trusted directories

Scoped file access — only the directory you launch from. Explicit approval for anything outside.

Enterprise MCP allowlist

Org admins control which MCP servers are permitted. Fail-closed enforcement — blocked if policy unreachable.

Deny precedence

Deny rules always override allow rules, even with --allow-all. Defense in depth.

Approval responses

y once, ! always this session, n deny once, # deny always, ? show details.

BYOK / Offline

Bring your own model provider — Ollama, Azure, Anthropic. COPILOT_OFFLINE=true disables all telemetry.
