Custom instructions

REPOSITORY + PATH

Custom instructions give Copilot project rules automatically. Use repository-wide rules for all files or path rules for a matching folder.

.github/
  copilot-instructions.md # all files
  instructions/api.instructions.md
    applyTo: "src/api/**"

How to use them

Write short rules in the file for the right scope. Set applyTo for path-specific rules.

Benefit: Copilot gets the right conventions without a repeated prompt.
Do not repeat a rule in several files if one scope is enough.Custom instructions

Prompt files

TASK TEMPLATES
TASK TEMPLATE.github/prompts/review-endpoint.prompt.md
# review-endpoint.prompt.md

Review API inputs, errors, and tests.
Return findings with file paths.
Do not edit files.

A prompt file stores a task you select in chat. Benefit: repeat a review without retyping it.

WHERE

.github/prompts/name.prompt.md

HOW

Write the goal and expected result, then select the file in chat.

Instructions are applied by scope; prompt files are selected for a task.Prompt files
