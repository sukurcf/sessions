01 · Remote Control

Start anywhere. Finish everywhere.

  • Start a Copilot session in VS Code or CLI
  • Type /remote on — session goes live on GitHub Mobile & web
  • Monitor progress in real-time from your phone
  • Send follow-up instructions mid-flight to steer the agent
  • Review changes, create PRs, and merge — all from mobile
Generally Available
Your Copilot agents don't stop when you leave your desk. Multi-surface, continuous workflow — laptop, web, and mobile are now one experience.
THE WORKFLOW
/plan → scaffold with Copilot CLI
/remote on → monitor on mobile
Steer → send follow-ups from anywhere
Review → approve changes on the go
Merge → done, from your phone

02 · Agents Window

One developer. Multiple agents. Parallel projects.

  • Brand new window type in VS Code — purpose-built for agents
  • Run multiple agent sessions across different repos simultaneously
  • Each session is independent — different branches, different tasks
  • Switch between active sessions like browser tabs
  • Choose your agent harness, isolation mode, and environment
  • Now available in VS Code Stable (previously Insiders-only)
Preview in VS Code Stable
This is the shift from "AI pair programmer" to "AI engineering team." You're now a manager of parallel agents, not a single-threaded coder.

03 · Agent-Browser Interaction

Agents can now see your app — in real time.

  • Share browser tabs with the agent via drag-and-drop or context picker
  • Agent reads page content, interacts with elements, validates changes
  • Edit code → reload page → verify fix — all in one agent turn
  • Privacy-first: explicit sharing required, stop sharing anytime
Available in VS Code 1.119+
Copilot doesn't just write code anymore — it can see the result. This closes the feedback loop every frontend developer has been waiting for.

04 · AI Risk Assessment

Think before you execute — AI-powered safety net.

  • Every terminal command gets an AI-generated risk badge
  • One-sentence explanation of what the command actually does
  • Three risk levels with clear color coding
  • Large outputs auto-compressed before sending to the model
Experimental
CommandRiskExplanation
cat README.md 🟢 Safe Reads and displays file contents
npm install lodash 🟠 Caution Installs package, modifies node_modules
git push --force origin main 🔴 Review Overwrites remote history, may lose commits
As agents become more autonomous, safety becomes critical. This gives developers confidence to let agents run — with guardrails they can trust.

05 · OpenTelemetry Observability

Full visibility into what your agent is doing.

  • Agent sessions emit OpenTelemetry traces, metrics, and events
  • Follows GenAI semantic conventions — works with any OTLP backend
  • See every tool call, LLM request, and decision in a waterfall trace
  • Track token usage (including cache hits) per model per turn
  • Works with Copilot CLI, local agents, and Claude agent
