Release review · 2026

What changed in GitHub Copilot.

A dated review of the most useful new capabilities across models, agents, code review, IDEs, the CLI, the Copilot app, and enterprise controls.

Window: 15 Jul - 15 Sep 2026 · verified against official GitHub Changelog and VS Code release notes

I.Models · July to September03

The model shelf expanded.

New choices target different tradeoffs: long-horizon agents, terminal work, image understanding, lower-cost coding, and general-purpose reasoning.

GA · Aug 6

Kimi K3

Open-weight model for agentic coding with provider-list usage billing. Rolling out to Pro, Pro+, Max, Business, and Enterprise; Business and Enterprise enable it explicitly.

Rollout · Aug 11

MAI-Code-1.1-Flash

Native vision plus better coding quality, instruction following, tool use, and performance. GitHub reported a 73% lower list price than its predecessor.

Rollout · Aug 13

Gemini 3.7 Flash

Improvements in web and app development, agentic coding, codebase research, and verification. Business and Enterprise policy is off by default.

Rollout · Aug 14

Grok 4.6

xAI reasoning model aimed at long-horizon terminal tasks and sustained tool use across Visual Studio Code and Copilot CLI.

GA · Sep 1 / 4

Claude Fable 5.1 + GPT-6 Astra

Two long-horizon models for autonomous coding and knowledge work. Availability is gradual and usage is billed at provider pricing.

Available · Sep 3

Gemini 3.8 Flash

Strong early results on complex terminal coding, validation, and recovery. Introductory provider pricing applies through December 31, 2026.

Sources: Kimi K3 · MAI-Code · September model releases

II.Models · control and economics04

Model choice became policy.

The new controls make cost, quality, reasoning depth, model availability, and usage evidence visible to both developers and administrators.

Sep 14 · rollout

Auto: Efficiency, Balance, Intelligence

Choose how GitHub Copilot weighs cost, quality, and latency. Auto still evaluates each prompt and selects from the available model set.

Aug 3 · all paid plans

Cloud-agent reasoning level

Choose more or less reasoning for supported models when delegating work. Higher reasoning can improve complex tasks but consumes more credits.

Jul 29 / Aug 26

Default model enablement

GA models can inherit a global Business or Enterprise default. Explicit choices remain intact; open-weight and data-retention-excluded models stay out.

Jul 31 · preview

Team-targeted model policies

Enterprise teams can receive optional models on top of an enterprise baseline, matching access to roles, training, or frontier experimentation.

Aug 11 · reporting

Per-model token breakdown

Usage reports now show input, output, cache-read, and cache-write tokens beside AI credits, making model cost easier to explain.

Aug 28 · Visual Studio

Model management

Pin favorites, hide unused models, compare capability and cost, and adjust thinking effort with Low, Medium, or High controls.

III.Agents · Visual Studio Code05

The Agents window became a workspace.

July through September releases make sessions easier to isolate, continue, compare, review, automate, and connect to GitHub work.

July · 1.127-131

Agent sessions, worktrees, and multi-chat

Use isolated worktrees, quick chats, peer chats, grouped sessions, subagent status, and pull request update banners.

July · 1.131

Vision, PDFs, and BYOK

Copilot Vision is generally available for images and PDFs. BYOK models now work in the Agents window, with ! for terminal commands.

1.132-133

Side questions and portable plugins

Use /btw for a context-sharing side chat, keep prompt sticky scroll, and install Agent Plugins 1.0 packages.

1.135-136

Continue and critique

Continue sessions created elsewhere, ask a complementary model for a second opinion with /rubber-duck, and organize related chats.

1.136

Agent Merge

Ask an agent to address review feedback, failed checks, and merge conflicts until a pull request is ready to merge.

1.137 · Sep 9

Automations, voice, and GitHub context

Schedule recurring agent work, talk and interrupt by voice, attach issues and pull requests in any chat, and continue quick chats into a workspace.

Sources: July VS Code releases · VS Code 1.137

IV.Agents · CLI and app06

Agent work became resumable.

The GitHub Copilot CLI and GitHub Copilot app now expose the controls needed for parallel work, recovery, customization, and cost visibility.

# August CLI additions
/tasks manage subagents and their tasks
/rewind restore changes without Git
/worktree isolate a parallel workspace
/app open the app with session context

# headless plan then implementation
gh copilot -p "Fix the failing test" --plan --mode autopilot

The CLI also queues prompts while a turn runs and moved to a native Rust runtime for faster performance.

Aug 25

Customize tab

MCP servers, plugins, skills, canvases, and Azure DevOps work now have one discovery surface in the GitHub Copilot app.

Aug 7

Auto transparency

Auto can show the model used for each request, with AI credit and cache details when available.

Aug 10

Ask in side chat

Open a parallel conversation about an agent question while the original task waits for your answer.

Aug 25

WSL and layout

Use a Linux environment through WSL, split tabs, and send browser previews to an external browser.

V.Agents · shared collaboration07

Start where the conversation is.

GitHub Copilot sessions can now begin in team chat, continue in the app or IDE, and end as reviewable repository work.

Slack · Aug 21

@GitHub shared agent sessions

Investigate failures, update or create issues, implement changes, validate in a cloud sandbox, and open a pull request from a conversation. Teams can inspect and redirect the same session.

Microsoft Teams · Aug 21

Turn meeting decisions into work

Mention @GitHub in a channel, thread, or direct message. Participants can add context and steer the cloud agent; repository admins can require an additional approval.

JetBrains · Sep 8

/ide connects CLI to the IDE

Connect a terminal session to JetBrains selections, diagnostics, file references, environment variables, and the project Python interpreter.

Cross-surface

Continue without re-explaining

Agent Host, app, CLI, VS Code, JetBrains, GitHub.com, and Mobile now share more session and context continuity across the same work.

Sources: Slack · Microsoft Teams

Customize once, use across clients.

Agent Plugins 1.0 standardizes a portable package for skills and MCP servers, while memory and project context reduce repeated setup.

# one portable plugin

VS Code · CLI · SDK · app
Aug 12

Agent Plugins 1.0

Build a plugin once. Compatible clients can discover the skills and MCP configuration they support from the same package. Existing plugins remain supported.

Aug 11

Copilot Memory

In JetBrains, GitHub Copilot can retain useful project details and preferences across agent chat sessions.

Sep 8

Global project context

Add global files and folders to JetBrains chat for changes that span multiple areas of a project.

Aug 24

Copilot harness

The JetBrains harness reached GA, with built-in JetBrains MCP support in public preview and direct /review integration.

VII.Review · quality and approval09

Code review gained judgment.

GitHub Copilot code review now offers configurable depth, richer context, broader pull request coverage, and an explicit approval path.

Aug 7 · GA

Lite and Balanced effort

Use Lite for straightforward changes and Balanced for deeper analysis. Organizations can set a default inherited by repositories.

Jul 29 · GA

Skills and MCP context

Reviews can use repository skills and read-only MCP connections. Comments show when that additional context contributed.

Aug 27

Bots, cloud agents, large PRs

Review bot-authored and Copilot cloud-agent pull requests, and review PRs beyond the former 300-file or 20,000-line limit.

Sep 1 · preview

Approval assessments

Every review signals whether the pull request appears ready. Admins can authorize an approval that counts toward required approvals.

Sep 11

Automatic resolution

Addressed comments resolve during rereview, autofix suggestions get smart commit messages, and Lite uses an ensemble of agents.

Sep 11

Deeper validation

The review agent can use the Copilot SDK shell tools behind its firewall to run builds, tests, scripts, and available tool calls.

Source: Copilot code review updates

VIII.Enterprise · guardrails10

More agent power came with more control.

Enterprise administrators can now define what agents may do, what context they may read, which tools they may connect to, and how policies vary by team.

Sep 9

Deny, ask, allow permissions

Manage shell commands, file reads, file edits, and network domains centrally in the GitHub Copilot app, CLI, and VS Code Agent Host.

Sep 2

Content exclusions reach app and CLI

Enterprise, organization, and repository exclusions now keep sensitive files out of agent context across these surfaces.

Aug 6

MCP allowlists

Allow or deny MCP servers by URL, command, or name. Policies fail closed and can be layered with team overrides.

Jul 31 / Aug 3

Team-specialized managed settings

Mark selected settings overridable and map files to enterprise teams while keeping the enterprise baseline as the floor.

Sep 8 · JetBrains

Managed sandbox policies

Control filesystem and network access, proxies, developer tools, Keychain access, and sandbox enablement in JetBrains IDEs.

Sep 2

Any default model

Business and Enterprise admins can set a default model for new conversations and specialize that default by enterprise team.

IX.Automation · measurement11

Agents can now run on a schedule and show their cost.

The release window added recurring work, event-driven work, voice interaction, and better evidence for adoption and spend.

Sep 9 · VS Code

Scheduled automations

Run recurring agent tasks hourly, daily, or weekly, or on demand. Templates cover change catch-up, issue triage, and bug finding.

Aug 3

Comment-triggered cloud work

Use an issue or pull request comment to generate documentation, investigate errors, or create follow-up tasks.

Sep 9 · VS Code

Voice Mode

Talk to an agent while it works, interrupt it, or redirect it. Gradual rollout; not available with Business or Enterprise plans.

Sep 11

VS Code Agents metrics

Usage reports add dedicated Agents-window users, sessions, and message counts at aggregate and user levels.

Aug 11

Token-level usage reporting

Admins and individual users can attribute AI credit consumption to input, output, cache reads, and cache writes by model.

Aug 7

Impact dashboard ROI view

Compare estimated cost per developer with pull request output across passive and agent-first adoption cohorts.
