Token optimisation for Copilot

Output tokens cost 3–5× more than input. Agent mode costs 5–25× more than Ask mode. Small habit changes — terser prompts, scoped context, the right surface, the right model — compound into large savings once AI Credits are your billing unit. This guide collects the highest-leverage techniques across practices, tools, and observability.

Foundation · Best practices

General strategies to reduce token consumption while maintaining output quality.

Be specific in prompts

Vague prompts cause back-and-forth cycles, and every revision costs tokens. Front-load context: language, framework, constraints, and expected output format.

PromptingAll surfaces

Use completions over chat

Inline tab completions and comment-driven suggestions consume far fewer tokens than a chat round-trip. For a small function or loop, a descriptive comment + tab beats opening chat.

CompletionsLow cost

Scope context surgically

Never ask the AI to "read the codebase". Most tasks touch 2–3 files — point at them with #file references. If you need to read a file yourself, do it yourself; don't load it into context.

Context windowPrecision

Break down large tasks

Decompose features into smaller, focused steps. Smaller requests produce better results with fewer retry tokens and less wasted output on wrong approaches.

DecompositionQuality

Accept & edit, don't regenerate

If a suggestion is 80% right, accept it and edit the rest manually. Regeneration re-reads the full context and produces a full new response — doubling cost for marginal gain.

WorkflowSavings

Understand context accumulation

Every message re-reads the entire conversation. Message 40 costs far more than message 5 — tool outputs, file reads, and command results stack permanently. New topic = new conversation.

Core mechanicSession hygiene

Use /compact proactively

Don't wait until context is bloated. Run /compact after each sub-task — it summarises and compresses history, keeping the thread alive but dropping the raw weight. Highest-leverage habit for long sessions.

CLI & chatHigh leverage

Keep session notes

End each session by asking Copilot to summarise key decisions and next steps to a notes file. Start the next session by loading that file — carrying forward only what matters, not 200 messages of accumulated context.

WorkflowCarry-forward

Don't use AI for your own reads

Reading a log, an API response, or a data file? Do it in your terminal or editor. Every file the AI reads gets appended to context permanently. Keep AI context for tasks that actually need AI.

DisciplineHygiene

Reduce reasoning effort

Extended thinking can burn tens of thousands of output tokens per request. For renames, simple edits, and quick lookups, lower the effort level. Don't under-invest on architecture, don't overspend on mechanical work.

Output costThinking

Write caveman prompts

Drop articles, filler, pleasantries, hedging. Pattern: [thing] [action] [reason]. "Refactor function. Fix auth. Make efficient." conveys the same intent as a 40-token polite version at 10 tokens. Real-world: 30–50% savings on input.

Prompt compression30–50%

Constrain output format

Output tokens cost 5× input. One line — "Code only, no explanation" — in copilot-instructions.md cuts output cost 40–70% on every code task. Other wins: "one sentence", "3 bullets max", "Yes/no, then one line why".

5× multiplier40–70%

Compress your instructions file

Your .github/copilot-instructions.md is loaded on every interaction. A 200-line file burns ~1,500 tokens per call before you type anything. A 6-line, ~50-token version saves ~72,500 tokens over 50 interactions.

Always-onHigh leverage

Use declarative guardrails

Imperative instructions ("First read X, then Y, then Z…") are long and fragile. Declarative invariants ("All exported functions: JSDoc required.") are short, stable, and compose. Five invariants stack; five procedures interfere.

Surface-specific · Tools

Token-efficient features and tools across each Copilot surface.

VS Code — Inline completions

Tab completions use far fewer tokens than chat. For small snippets, let inline suggestions do the work. Use Next Edit Suggestions and Copilot Edits for multi-file changes instead of chat-based iteration.

VS CodeCompletions

VS Code — Vision & references

Drag images into chat for UI work instead of describing layouts in text. Use #file, #selection, #codebase to provide precise context without pasting code into the prompt.

VS CodeContext

VS Code — Agent mode

Agent mode iterates autonomously, but every tool output stacks into context permanently — each loop compounds the cost of every subsequent message. Set approval to Auto thoughtfully and watch for runaway loops. Reserve agent mode for tasks that genuinely need autonomy.

VS CodeAgentic

Copilot CLI

Use sub-agents (explore, task) for parallel work — smaller, cheaper models with isolated context. Use grep / glob / view for simple lookups. Know the difference: /compact summarises; /clear wipes.

TerminalSub-agents

Copilot Cloud Agent

Write detailed issues with clear acceptance criteria — vague issues cause more exploration loops. Use copilot-setup-steps.yml to pre-install dependencies so the agent doesn't burn tokens figuring out the environment.

CloudAutonomous

Model selection

Default to Auto. Auto chooses from the supported pool and applies a discount on paid plans. Override only when needed: fast (Haiku) for renames, standard (GPT-4.1, Sonnet) for daily work, premium (Opus) for architecture. Teams switching from "always Sonnet" to "Auto, override when needed" generally reduce spend.

Cost controlAll surfaces

Delegate to sub-agents

Tasks needing many file reads or long analysis belong in a sub-agent — separate session, isolated context. You get the result without the session weight landing in your main conversation. Anything touching more than 3–4 large files is a candidate.

CLIIsolation

Exclude files from context

Use .copilotignore (or equivalent) for build artefacts, lock files, logs, node_modules. Anything Copilot doesn't need shouldn't be visible — but don't over-prune; excluding files Copilot actually needs causes worse suggestions and more retries.

ConfigurationOne-time

Prefer CLI tools over MCP

Where a CLI equivalent exists, use it. A shell command returning 10 lines costs 10 tokens of context. The same request through an MCP server might return a JSON blob 100× larger — and the full output lands in context permanently.

MCPReduction

VS Code — Copilot Edits

For multi-file refactors, use Copilot Edits instead of asking chat to generate code you copy-paste. Edits applies changes directly across files in one operation — fewer round trips, less context, no manual transfer overhead.

VS CodeMulti-file

Choose Ask, Edit, or Agent

Agent mode costs 5–25× more than Ask for the same prompt — it triggers many internal LLM calls, file reads, and tool evaluations. "What does this function do?" → Ask. Single-file change → Edit. Multi-file refactor with clear scope → Agent. Never use Agent for a vague prompt.

5–25×60–90% savings

Scope instructions with applyTo

Split a big copilot-instructions.md into a small always-on core plus scoped files in .github/instructions/. Each takes an applyTo glob — Copilot only loads it when editing matching files. Flipping the always-on/scoped ratio cuts per-interaction context 50–80%.

Configuration50–80%

Audit your MCP servers

Each MCP tool definition costs 100–500 tokens — loaded every agent step. 10 servers × 5 tools × 200 tokens × 15 steps = 150K tokens just describing tools. Disable what you don't need; use workspace .vscode/mcp.json instead of enabling everything globally.

Observability · Monitor your usage

Track and understand your Copilot consumption to stay in control.

AI Credit tracking

Monitor usage at github.com/settings/copilot. From June 2026, Copilot uses usage-based billing — every interaction consumes AI Credits at published per-model rates. 1 AI Credit = $0.01 USD. Code completions and Next Edit suggestions remain unlimited.

SettingsDashboard

Know your per-token costs

Models have vastly different per-token rates. Output costs 3–5× input. Agent mode and Cloud Agent sessions consume far more tokens per task than chat or completions because they run multiple internal LLM calls. Match model and surface to the value of the task.

AwarenessAI Credits

Model pricing tiers

Lightweight (GPT-5 mini, Gemini 3 Flash) cheapest. Versatile (GPT-4.1, Sonnet, Haiku) mid-range. Powerful (Opus, GPT-5.5, Gemini 2.5 Pro) most expensive. All draw from the same AI Credit pool — choosing the right tier per task is the primary cost lever.

BillingTiers

Build personal habits

Periodically review your AI Credit consumption and reflect on which workflows cost the most. Long chat threads on expensive models? Could inline completions have done it? Small habit changes compound into big savings.

HabitsSelf-audit

CLI session awareness

In Copilot CLI, use /usage to see current-session usage. Use /compact regularly to compress history and free up context. Watch for long-running agent loops that may burn through tokens.

CLIReal-time

Billing & plan management

Review included AI Credits at github.com/settings/billing. Each plan includes credits matching its price ($10 Pro, $39 Pro+, $19/user Business, $39/user Enterprise). Business and Enterprise pool unused credits across the org. Admins can set budgets at enterprise, cost-centre, and user levels.

BillingPlans

Set a baseline first

Before optimising, measure. Pick a representative task, note AI Credits consumed, then apply optimisations and re-run. Without a baseline you're guessing — the comparison is your signal, not generic percentage claims.

MeasurementBefore/after

Recognise context overload

Context overload doesn't always show up as a bill — sometimes as errors. Frequent internal errors, dropped connections, or "chat has reached its limit" messages mean context is too large. Don't retry — /compact or start fresh.

Error signalsDebug

Watch for runaway loops

Agent mode and sub-agents can loop — retrying failed commands, re-reading files, exploring dead ends. Each iteration adds context and cost. If the AI is repeating itself or spinning on an error, intervene. A 30-second human fix beats 10 rounds of AI retries.

AgenticIntervention

Prune context files ruthlessly

Research shows LLM-generated context files (from /init or similar) hurt agent performance while increasing cost 20–23%. Agents already know how to ls and grep. Delete anything discoverable. Keep only landmines: things that look normal but cause mistakes ("Use uv not pip", "Don't refactor the auth module").

Research-backed20–23%

Keep commits & reviews terse

The Coding Agent reads git history and PR comments — every verbose commit or review costs tokens when ingested. Use Conventional Commits, subject ≤50 chars. For reviews, one-line format with severity prefix: "L42: 🔴 bug: user can be null. Add null guard." (~12 tokens vs ~40 for a paragraph). Compounds across a repo's history.
