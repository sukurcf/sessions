01 · Model roster

Start with Auto. Step up when it matters.

Rule of thumb: if the answer is weak, use a bigger model and retry.

Default

Auto

Auto picks a model for each task, based on task complexity.

On paid plans, Auto gives you a discount on model costs.

Keep Auto for most work.

Step up

Go bigger when

  • The change spans many files.
  • The design choice is hard.
  • A bug survives two or three tries.

Try GPT-5.6 Sol, Claude Opus 5, or GPT-6 Astra.

Step down

Go smaller when

  • The task is quick, like a rename.
  • The work is repetitive.

Try GPT-5.6 Luna, Claude Haiku 5.5, or Gemini 3.8 Flash.

02 · Agentic development in the IDE

Agent mode: plan, edit, verify

Open a local folder in VS Code. No repo setup needed.

1

Plan

Ask the agent to propose an approach first. Review it before any edit.

2

Edit

The agent finds the right files. It changes them across the folder.

3

Verify

The agent runs tests and fixes failures. You review the diff and test the behavior.

Try this prompt

The test "applies discount codes" fails.
Fix the bug. Do not change the public API.
Run the tests. List the files you changed.
  • Ask for a plan first on a large task.
  • Use Plan mode when it is available.
  • Read every diff before you keep it.

02 · Agentic development in the IDE

Custom skills: your own /slash commands

A skill is a folder with a SKILL.md file. It holds instructions for one task.

Where skills live

Project Shared in the repo

.github/skills/release-notes/SKILL.md

Personal Only for you

~/.copilot/skills/release-notes/SKILL.md

Type /release-notes v2.4 to run a skill with extra context. Type /skills to open the skills menu.

---
name: release-notes
description: Write release notes from PRs.
---
1. List PRs merged since the last tag.
2. Write one line per change.

Rules: name uses lowercase letters, numbers, and hyphens. It must match the folder name. description says what the skill does and when to use it.

02 · Agentic development in the IDE

Copilot CLI: faster, reversible, multi-session

Faster runtime

  • The CLI runtime moved from TypeScript to Rust in 2026.
  • Performance improved by orders of magnitude.

/rewind: undo a bad turn

  • Press Esc twice when idle, or type /rewind (or /undo).
  • Pick a past prompt. Keep the conversation, or restore its files too.
  • Rewind cannot be undone. It restores only files Copilot changed.

Multi-session workflow

  • Run several sessions. Each has its own rewind points.
  • Press ← to open the sessions sidebar. Press n to start one.
  • Resume an earlier session with copilot --resume=<session-id>.

03 · Copilot beyond the editor

The GitHub Copilot app (desktop)

Generally available since June 17, 2026, on macOS, Windows, and Linux.

Work in parallel

  • Start from an issue, a pull request, or a prompt.
  • Run parallel sessions. Each has its own branch and worktree.
  • Review the diff, then open a pull request.

New in the app

  • Canvases: work with the agent on one plan, PR, or terminal.
  • Cloud automations: run agent work on a schedule.
  • Pick a model per session. Connect MCP servers.

Business and Enterprise: an admin must enable Copilot CLI in policy settings. Run copilot app in a folder to open the app there.

03 · Copilot beyond the editor

Copilot on GitHub.com (web)

Ask questions and delegate work in your browser. No local setup needed.

1

Ask

Ask chat about your repositories, code, and options.

2

Delegate

Start from an issue, a pull request, a chat, or the agents panel. The work runs in the cloud.

3

Review

Copilot creates a branch, writes commits, and pushes. You review, then open a pull request.

Also: Copilot reviews pull requests and suggests fixes. Automations run repository tasks on a schedule or on events. With syncing on, you can ask about sessions from CLI, VS Code, JetBrains, and the app.

Key takeaways

  1. 1Keep Auto. Step up to a bigger model only when the answer is weak.
