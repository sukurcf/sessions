V. Agentic · IDE 06

Agent mode.

Copilot works autonomously in your IDE — determining which files to edit, proposing terminal commands, and iterating until the task is complete. Runs on Local, CLI, Cloud, or Third-party (Anthropic/OpenAI) agent types.

Multi-file planning

Agent analyzes your codebase, creates an implementation plan, edits files across the project, and runs terminal commands.

Self-correcting loop

When tests fail or linter errors appear, the agent reads the output, diagnoses the issue, and fixes it — without waiting for you.

Tool invocation

Agent can read/write files, search code, run terminal commands, fetch web pages, and invoke MCP tools — all in one session.

Multi-model support

Choose from GPT-5.5, GPT-5.4, Claude Opus 4.7, Claude Sonnet 4.6, Gemini 3.5 Flash, Gemini 3.1 Pro, and more. Switch models mid-conversation.

VI. Agent sessions 07

Agent sessions.

Run multiple agent sessions in parallel. Each session works independently — plan a feature in one session while refactoring in another. Monitor progress from the Sessions view.

Parallel sessions

Run multiple sessions simultaneously. Each gets its own working set of files and terminal.

Sessions view

Monitor all active sessions from the sidebar — see status, switch between them, review changes.

Background agents

Send a session to the background while it works. Get notified when it's done or needs your input.

Available in VS Code · Sessions view: View → Open View → Chat Sessions

VII. Built-in agents 08

Three built-in agents.

The agent picker in VS Code's chat view lets you choose a role for the AI. Each built-in agent gives Copilot a different level of autonomy.

Ask

Answers questions about coding concepts, your codebase, or VS Code itself — without making any file changes.

Use when: Onboarding, exploring legacy code, preparing for code reviews.

Plan

Creates a structured implementation plan before writing code. Hands the plan off to an implementation agent when approved.

Use when: Architecting features, mapping multi-step changes before coding.

Agent

Autonomously edits files, runs terminal commands, invokes MCP tools, reads errors, and self-corrects in a loop.

Use when: Feature implementation, bug fixes, scaffolding, migrations.

VIII. Custom agents 09

Custom agents.

Specialized agents defined in .agent.md files. Select from the agent picker or generate with /create-agent.

// .github/agents/security-reviewer.agent.md
---
name: Security Reviewer
description: Reviews for OWASP Top 10
tools: [read_file, grep_search]
handoffs:
  - label: Start Implementation
    agent: implementation
---

You are a security-focused code
reviewer. Analyze for injection,
auth, and data exposure.

File-based definition

YAML frontmatter for name, tools, model. Body is the system prompt. Also supports Claude format in .claude/agents/.

Handoffs between agents

Transition buttons: Plan → Implementation → Review. Each carries context and a pre-filled prompt.

Multi-surface reuse

Same agents work in local, Copilot CLI background, and cloud agents.

Org-level sharing

Define at GitHub org level. VS Code auto-discovers for all members.

.github/agents/ · .claude/agents/ · ~/.copilot/agents/ · Generate: /create-agent in chat

IX. Agent skills 10

Agent skills.

Skills are folders of instructions, scripts, and resources that Copilot loads when relevant. Based on an open standard (agentskills/agentskills), they work across cloud agent, Copilot CLI, and VS Code agent mode.

Project & personal skills

Project skills live in .github/skills/, .claude/skills/, or .agents/skills/. Personal skills in ~/.copilot/skills/ shared across all projects.

Discover & install

Use gh skill in GitHub CLI to discover and install skills from any GitHub repo. Community collections at anthropics/skills and github/awesome-copilot.

Cross-surface support

Skills work identically in Copilot cloud agent, Copilot CLI, and VS Code agent mode. Org/enterprise-level skills coming soon.

Open standard

Based on the Agent Skills open specification. Used by multiple AI systems — not locked to GitHub Copilot.

Source: docs.github.com/copilot/concepts/agents/about-agent-skills (May 2026)

XI. Agentic · CLI 12

GitHub Copilot CLI.

Standalone terminal agent (copilot command — gh copilot extension is retired). Default model: Claude Sonnet 4.5.

# Interactive session
copilot

# Programmatic — single prompt
copilot -p "Add validation"
  --allow-tool='shell(npm)'

# Full auto with deny list
copilot --allow-all-tools
  --deny-tool='shell(rm)'
  --deny-tool='shell(git push)'

Plan mode

Press Shift+Tab to toggle. Copilot analyzes scope, asks clarifying questions, and builds a plan before writing code.

Auto context management

At 95% token limit, auto-compresses history in the background — enabling virtually infinite sessions.

ACP & MCP native

Use as an agent in third-party tools via ACP. Connect MCP servers for databases, APIs, and custom tools.

Bring your own model

Connect OpenAI-compatible, Azure, Anthropic, or local models (Ollama). Set via COPILOT_PROVIDER_BASE_URL.

All plans · Standalone install · Source: docs.github.com/copilot/concepts/agents/copilot-cli

XII. CLI · Slash commands 13

CLI slash commands.

Inside a copilot interactive session, use slash commands to control the agent, manage context, and adjust permissions — all without leaving your terminal.

/compact

Manually compress conversation context. Also auto-triggers at 95% token limit. Enables virtually infinite sessions.

/context

Show a detailed token usage breakdown — see exactly how your context window is being used across the session.

/model

Switch AI model mid-session. Select from models with premium request multipliers (e.g., Claude Sonnet 4.5 at 1x).

/mcp

List configured MCP servers and their tools. Inspect what external capabilities the agent can invoke.

/allow-all

Allow all tools for the rest of the session without individual approval prompts. Equivalent to --allow-all-tools.

/yolo

Full auto mode — skip all approval prompts and let the agent run everything. Use in trusted/sandboxed environments only.

/delegate

Hand off the current task to the cloud agent. It continues the work remotely and opens a pull request when done.

/feedback

Submit feedback — private survey, bug report, or feature request. Helps improve the CLI directly from your session.

Shift+Tab

Toggle between ask/execute mode and plan mode. In plan mode, Copilot builds a structured plan before writing any code.

XIII. Agentic · Cloud 14

GitHub Copilot cloud agent.

An autonomous AI agent that runs remotely on GitHub infrastructure. It researches your repository, creates an implementation plan, makes code changes on a branch, and opens a pull request. Supports custom agents, MCP servers, and centralized agent management.

Issue → Pull request

Assign a GitHub issue to Copilot. It reads the issue, explores the repo, writes code, runs CI, and opens a PR for human review.

Auto model selection

Cloud agent picks the best model for cost and complexity automatically. Override with a specific model if needed.

One-click CI fixes

When GitHub Actions fail, click "Fix with Copilot" to have the agent diagnose and fix the issue. Ships a new commit automatically.

Firewall & policies

Org admins control which repos can use cloud agent, what tools are allowed, and what models are available. MCP servers also supported. Built-in security risk mitigations.

Pro, Pro+, Business, Enterprise · Uses premium requests · Source: docs.github.com/copilot/concepts/agents/cloud-agent (May 2026)

XIV. Agentic · Review 15

Code review agent.

AI-powered review that catches bugs, security issues, and style violations. Uses agentic capabilities with full project context gathering (GA). Can pass suggestions to cloud agent for auto-fix (preview). Available on GitHub.com, CLI, Mobile, VS Code, Visual Studio, Xcode, and JetBrains.

Automatic PR review

Configure per-user, per-repo, or per-org. Reviews on open, on each push, or even on draft PRs. Assign Copilot as a reviewer.

Full project context (GA)

Agentic capabilities analyze your entire repository for contextually aware reviews. Runs on GitHub Actions runners.

Auto-fix with cloud agent

Pass suggestions to cloud agent to auto-create a PR with fixes applied (preview). Enhanced with custom instructions and Copilot Memory.

XV. VS Code UX 16

VS Code agent UX.

Two surfaces for working with agents: the main editor window (editor-first) and the new Agents window (agent-first, preview). Both share sessions, settings, and keybindings.

Agents window (preview)

A dedicated agent-first surface for orchestrating sessions across multiple projects. Chat and sessions list as the primary interface, with Changes and Customizations panels.

Agent Logs & Chat Debug

Agent Logs shows chronological tool calls, LLM requests, and prompt file discovery. Chat Debug shows raw system prompt, context, and tool payloads.

Agent type picker

Select where agents run: Local (interactive in editor), Copilot CLI (background on your machine), Cloud (remote with PR integration), or Third-party (Anthropic, OpenAI).

Permission levels

Default Approvals (safe tools auto-approved), Bypass Approvals (all auto-approved), Autopilot preview (fully autonomous, auto-responds to questions).

Source: code.visualstudio.com/docs/copilot/agents/overview (May 2026)

XVI. Enterprise 17

Enterprise controls.

All agent capabilities run inside the policies, security controls, and audit infrastructure Viasat already trusts.

Content exclusions

Org admins define which files and repos Copilot can never read or reference. Enforced at the platform level.

Audit logs

Every agent action — tool calls, file edits, terminal commands — is logged in the GitHub audit log for compliance review.

Policy controls

Enable/disable agent mode, cloud agent, CLI, and specific models per org or enterprise. Granular feature flags.

IP indemnity

Enterprise plan includes IP indemnity for Copilot-generated code. Business and Enterprise only.

No training on your code

Business and Enterprise: your code is never used to train models. Zero data retention after processing.

Org-managed instructions

Push custom instructions, agents, and skills from a central repo. All developers get consistent AI behavior.
