Agent workflow

Use agents to help with the work. Keep the final decision with the team.

  1. Define

    Write the goal, limits, and acceptance criteria.

  2. Build

    Assign a task to the coding agent.

  3. Review

    Run checks and request a Copilot review.

  4. Decide

    A person checks the result and merges it.

Assign a task

On GitHub.com, start with an issue in a repository where the cloud agent is enabled.

  1. Write

    Create an issue with a specific result and clear limits.

  2. Assign

    In Assignees, select Copilot and add any extra guidance.

  3. Follow

    Open the session log. Review the pull request and checks.

Availability depends on your plan, repository settings, and organization policy.

Sub-agents

A main agent delegates a focused task to a worker with its own context.

Main agentFrame

Give one bounded goal.

WorkerResearch

Work in a separate context.

WorkerReturn

Provide findings and evidence.

Main agentVerify

Use the result in the main task.

A sub-agent does not remove the need to verify its result.

Sub-agent brief

Make the delegated request self-contained.

Specify

  • One goal and the relevant files.
  • Allowed actions and tool limits.
  • The result, evidence, and stop condition.

MCP setup

Configuration is specific to the Copilot surface you use.

Custom agents

Define a reusable specialist role with instructions and a selected set of tools.

Use a custom agent when

  • A role has a repeatable responsibility.
  • It needs a specific result or tool set.
  • You want to share the role with a team.

Define and verify

  • Store a repository agent in .github/agents/.
  • Describe its role, limits, and expected output.
  • Test its tool use and result on a small task.

SDK example

TypeScript · Install @github/copilot-sdk
import { CopilotClient } from "@github/copilot-sdk";

const client = new CopilotClient();
try {
  const session = await client.createSession({
    model: "auto",
    onPermissionRequest: () => ({ kind: "reject" })
  });
  const reply = await session.sendAndWait({
    prompt: "Explain this repository."
  });
  console.log(reply?.data.content);
} finally {
  await client.stop();
}

This example rejects permission requests. Define a suitable permission policy for your app.
