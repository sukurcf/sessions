Overview · Nº 01

A cloud-native AI agent that codes autonomously.

The coding agent (also called the "cloud agent") is an autonomous AI developer that runs entirely in GitHub's infrastructure. Assign an issue, and it spins up a secure environment, writes code, and opens a pull request — without you touching your editor.

  • Runs in a dedicated, sandboxed GitHub Actions environment.
  • Has full context of your repository — files, history, and dependencies.
  • Creates branches, commits code, and opens draft PRs automatically.
  • All changes go through your existing branch protections and CI/CD.

Under the hood · Nº 02

How it actually works.

When you assign an issue to @copilot, the agent kicks off a fully automated workflow. It operates asynchronously — you can close your laptop and come back to a finished PR.

  • Powered by GitHub Actions runners — isolated, ephemeral VMs.
  • Reads repo structure, README, contributing guides, and CI config.
  • Iterates autonomously: writes code → runs linting → runs tests → fixes failures.
  • Logs every step in a visible session — full transparency, no black box.
  • Cannot merge code — human review and approval always required.

Triggering · Nº 03

Assign an issue — Copilot does the rest.

The primary trigger is simple: assign a GitHub issue to Copilot, just like you'd assign it to a human teammate. You can also mention @copilot in issue comments.

  • Assign to Copilot — In any issue, click "Assignees" and select Copilot.
  • @copilot in comments — Write a comment like "@copilot please fix this bug" on any issue.
  • Copilot Chat in VS Code — Open Chat, select "Coding Agent" mode, describe the task, and hit send.
  • GitHub.com Copilot panel — Use the Copilot icon on any repo page to start a task.

Capabilities · Nº 04

What it can actually do.

The coding agent handles real development tasks end-to-end. It's best at well-scoped, single-repo tasks — think "good first issue" level and beyond.

  • Implement new features from a clear spec or issue description.
  • Fix bugs — reads stack traces, finds root cause, applies fixes.
  • Add or extend test coverage across your test suite.
  • Refactor code — rename, extract, restructure with confidence.
  • Update documentation, READMEs, and inline comments.
  • Respond to PR review feedback — iterate on its own PRs.
Best suited for
1Bug fixes with clear repro steps
2Adding tests for uncovered code
3Small-to-medium feature implementation
4Code refactoring and cleanup
5Dependency updates and migrations

Configuration · Nº 06

The setup file that shapes your agent.

Place a copilot-setup-steps.yml in your repo's .github/ directory. It tells the coding agent how to prepare its environment before it starts working on your code.

  • Install project dependencies (npm, pip, cargo, etc.).
  • Set up databases, services, or other infrastructure.
  • Configure environment variables the agent needs.
  • Define custom build or test commands.
  • Specify runner type (GitHub-hosted or self-hosted).
# .github/copilot-setup-steps.yml
steps:
  - uses: actions/setup-node@v4
    with:
      node-version: 20
  - run: npm install
  - run: npm run build

# Agent uses this to prep
# its environment before
# writing any code.

Controls · Nº 07

Enterprise-grade guardrails built in.

The coding agent respects your existing security and governance policies. Admins can fine-tune what the agent is allowed to do at the organization and repository level.

  • Enable / disable per repo — Org admins toggle access; repo owners can opt out.
  • Branch protections — Agent creates branches, never pushes to main directly.
  • Model selection — Choose which AI models the agent uses (GPT-4.1, Claude, etc.).
  • MCP servers — Connect external tools via the Model Context Protocol.
  • Firewall policies — Restrict outbound network access from the agent's VM.
  • Session logs — Every agent action is logged and auditable.
Settings Hierarchy
1Organization — global enable/disable, policies
↓
2Repository — opt-in/out, setup file, protections
↓
3Individual — model choice, MCP tools, instructions
