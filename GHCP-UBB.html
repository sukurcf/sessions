The Basics02 / 06

How billing works

Input
Input Tokens

What you send — your code context, file contents, and the prompt itself.

Output
Output Tokens

What the model generates — code suggestions, explanations, refactored snippets.

Cached
Cached Tokens

Context the model reuses from previous interactions — billed at a reduced rate.

( Input × Rate ) + ( Output × Rate ) + ( Cached × Rate ) = AI Credits 1 credit = $0.01 USD
Code completions & next-edit suggestions are free — unlimited on all paid plans
